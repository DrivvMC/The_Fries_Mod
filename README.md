# The_Fries_Mod v0.1
The Fries Mod is a Minecraft Java mod. It adds fries, fries and more fries.

Mod Additions:

New Mob: Fries Monster: It lives underground and if slain it drops fries.
New Item: Fries: This is edible and you can craft a block of fries.
New Dimension: The Fry World: Build a frame out of blocks of fries and craft a fries and steel by combining fries and a iron ingot.
